# Settle a payment (Rust)

Implement `settle` in `src/lib.rs`. Plan on 15 minutes. The rules are in [SPEC.md](SPEC.md).

Do not change `tests/sum_amounts.rs`.

## Run

From this directory:

```bash
cargo test
```

## Submit

This directory is only the Rust task. Create a branch and push it. Do not change `tests/`, `SPEC.md`, or `.github/`.

From this directory:

```bash
git checkout -b candidate/<your-name>
git add src/lib.rs
git commit -m "Implement settlement"
git push -u origin candidate/<your-name>
```
